# China Air Quality Analysis (PM2.5)

## 📌 Project Overview
This project analyzes PM2.5 air pollution levels across major Chinese cities using real-world air quality data. The goal is to explore pollution trends, seasonal patterns, and city-wise differences using data science techniques.

## 🌍 Cities Covered
- Beijing
- Shanghai
- Guangzhou
- Shenzhen
- Chengdu
- Xi’an
- Wuhan

## 📊 Objectives
- Analyze PM2.5 concentration trends over time
- Compare pollution levels across cities
- Identify seasonal and yearly patterns
- Perform exploratory data analysis (EDA)
- Visualize air quality insights using charts and maps

## 🧠 Methodology
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Statistical analysis
- Data visualization using Python libraries

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📁 Dataset
Publicly available air quality datasets related to Chinese cities (PM2.5 measurements).

## 🎯 Outcomes
This project demonstrates practical data science skills including data handling, analysis, visualization, and interpretation of environmental data for real-world impact.
